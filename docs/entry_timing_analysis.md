## 개요

더 빠른 **바닥 확인 진입** 방식의 실증 성과를 검증한 결과입니다.

## 전략 정의

### 전략 A — 기존 방식 (MA 정배열)
```
진입 조건: MA20 > MA50 > MA200 AND ADX≥20 AND RSI 50~77
           AND HH-HL≥2 AND 가격≥52주고점의 75%
```

### 전략 B — 바닥 확인 진입 (신규)
```
1단계: MA20이 MA60을 하향 돌파 (데드크로스) → 하락 구간 진입, 저점 추적 시작
2단계: 데드크로스 이후 형성된 최저점이 30 영업일(~6주) 동안 갱신되지 않음 → 바닥 확인
3단계: 바닥 확인 시점에 ADX≥20, HH-HL≥2, 52주고점≥75% 조건 충족 시 진입
※ RSI 조건 완화 (바닥 직후 RSI가 회복 중이므로 50 이하 가능)
```

### 전략 C — 3단계 점진 진입 (신규)
```
1단계: 바닥 확인 → 산출 비중의 50% 진입
2단계: 추가로 MA50 기울기가 하락→상승 전환 → 산출 비중의 80%까지 확대
3단계: 추가로 골든크로스(MA50 > MA200) 확인 → 산출 비중의 100% 가동
```

## 핵심 발견

### 1. 기존 MA 정배열 방식이 더 우수
기존 방식(A)이 바닥 확인 방식(B)보다 CAGR 기준 **+5.1%p 우위**를 보였습니다.

**원인 분석:**
- MA 정배열 조건은 이미 상승 추세에 진입한 종목만 선별 → **모멘텀 퀄리티 필터** 역할
- 바닥 확인 방식은 하락 후 회복 초기 종목을 포착 → 회복 실패 리스크 존재
- RSI 완화로 인해 낮은 모멘텀 종목이 포트폴리오에 포함될 수 있음
- 종목 레벨의 바닥 확인이 시장 지수 레벨(market_entry_analysis.md)과 다르게 작동

### 2. 모든 전략이 SPY 대비 압도적 우위
- 기존 방식: CAGR +29.7% vs SPY +13.0% → **+16.7%p 초과수익**
- 바닥확인: CAGR +24.6% → **+11.6%p 초과수익**
- MDD는 모든 전략에서 -0.6%~-1.0% → SPY의 -23.9% 대비 극히 낮음

### 3. 바닥 확인의 진정한 가치: 위험 분산
- 바닥 확인 방식은 CAGR은 낮지만 **MDD -1.0%로 매우 안전**
- 3단계 진입(C)은 점진적 진입으로 위험을 더욱 분산하되 수익성은 소폭 감소
- 투자 성향에 따라 선택 가능한 옵션을 제공

## 위양성(False Positive) 분석

> 바닥 확인 신호 발생 후 60 영업일 이내 종가가 확인 저점 아래로 하락하면 위양성으로 판정

| 구분 | 이벤트 수 | 위양성 | 비율 |
|---|---|---|---|
| **전체** | **2,074건** | **507건** | **24.4%** |
| US 시장 | 1,648건 | 371건 | 22.5% |
| KR 시장 | 426건 | 136건 | 31.9% |

**해석:**
- **75.6%의 바닥 확인 신호는 진양성** — 확인 후 신저점 없이 회복
- 위양성 24.4%: 바닥이라 생각했지만 추가 하락이 발생하는 케이스
- KR 시장(31.9%)이 US 시장(22.5%)보다 위양성이 많음 → 한국 시장의 복합 바닥형이 더 빈번
- **ATR 스톱로스 병행 필수**: 위양성 발생 시 스톱로스가 손실을 자동 제한

**market_entry_analysis.md 사례와의 비교:**

| 사례 | 예측 | 실제 |
|---|---|---|
| 코로나 2020 (V자) | 위양성 없음 예측 | ✅ 진양성 |
| 금융위기 2009 (V자) | 위양성 없음 예측 | ✅ 진양성 |
| 나스닥 2022 (복합) | 위양성 예측 | ✅ 위양성 발생 |

종목 레벨 백테스트에서도 시장 지수 분석과 동일한 패턴이 확인됩니다.

## 결론 및 권고

### 전략 선택 가이드

| 투자 성향 | 권고 전략 | 이유 |
|---|---|---|
| 수익 극대화 | **A (기존 MA정배열)** | CAGR +29.7%, 샤프 2.62로 최고 성과 |
| 위험 관리 중시 | **B (바닥확인)** | 빠른 진입 + ATR 스톱 조합, MDD -1.0% |
| 점진적 확신 | **C (3단계진입)** | 단계별 증량으로 심리적 안정감 제공 |

### 핵심 인사이트

1. **지수 레벨 바닥 ≠ 종목 레벨 바닥**
   market_entry_analysis.md의 SPY/나스닥 지수 분석 결과를 개별 종목에 그대로 적용하면 효과가 다를 수 있습니다. 지수가 바닥을 찍어도 개별 종목은 추가 하락 가능성이 있습니다.

2. **MA 정배열 조건의 모멘텀 필터 가치**
   "이미 상승 중인 종목만 선별"이라는 기존 방식의 단점처럼 보였던 특성이 실제로는 **모멘텀 퀄리티 필터**로 작동하며 수익성을 높이는 핵심 요인입니다.

3. **바닥 확인 전략의 활용**
   개별 종목 선별보다는 **시장 전체 진입 시점 판단**(market_entry_analysis.md에서 제안한 방식)에 더 적합합니다. 예: SPY 바닥 확인 시 전략 A의 비중을 높이는 방식.

4. **ATR 스톱로스는 필수**
   위양성 24.4% 환경에서 스톱로스 없이 운용하면 복합 바닥형(나스닥 2022 등) 에서 손실이 누적될 수 있습니다.
