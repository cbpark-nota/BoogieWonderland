## 백테스트 보류 사유

### SVXY 액면병합 / 구조 변경 이력

SVXY는 yfinance에서 제공하는 히스토리 데이터를 그대로 사용할 경우 **정상적인 백테스트가 불가능**합니다.

| 날짜 | 이벤트 | 내용 |
|------|--------|------|
| 2018-02-27 | 추종 배율 변경 | -1x → **-0.5x** 로 변경 (Volmageddon 이후) |
| 2018-02-27 | 사실상 구조 변경 | 기존 XIV(VelocityShares) 청산 후 SVXY 재설계 |
| 액면병합 이력 | 주가 연속성 단절 | yfinance 수정 주가가 역분할을 올바르게 반영하지 않을 수 있음 |

**핵심 문제:**
- 2018년 이전 데이터는 -1x 배율 기준이며, 이후는 -0.5x 기준 → 단순 연결 시 수익률 왜곡
- yfinance의 `auto_adjust=True` 옵션이 배율 변경을 반영하지 않음
- 액면병합(reverse split) 적용 기준 시점이 불명확하여 수익률 계산 오류 발생

### SVIX 데이터 한계

| 항목 | 내용 |
|------|------|
| 출시일 | 2022-03-22 |
| 데이터 기간 | 약 4년 (2022~2026) |
| 주요 VIX 이벤트 포함 여부 | COVID-19(2020), Volmageddon(2018) **미포함** |

SVIX는 2022년 출시로 역사적 대형 VIX 이벤트에 대한 실데이터가 없어 극단적 리스크 검증 불가.

### VIX 선물 지수(SPVXSP) 데이터 부재

이론가 계산의 핵심 입력값인 SPVXSP(S&P 500 VIX Short-Term Futures Index) 히스토리가 yfinance에서 제공되지 않습니다. VIX 현물 변동률로 근사하는 방식은 실제 선물 지수와 편차가 크며, 백테스트 신뢰도를 크게 떨어뜨립니다.

## 정상적인 백테스트를 위한 데이터 보정 방안

### 1. SVXY 데이터 보정

```
[방법 A] 2018-02-28 이후 데이터만 사용
  - -0.5x 구간만 백테스트 (2018-02 ~ 현재, 약 8년)
  - 단: 대형 이벤트(2020 COVID)는 포함, Volmageddon(2018-02-05)은 미포함

[방법 B] XIV + SVXY 연결 (수동 스케일 조정)
  - 2018-02-27 이전: XIV(-1x) 수익률을 0.5 배율로 스케일 다운하여 SVXY 추정
  - 데이터 소스: XIV Yahoo Finance (^XIV 또는 별도 CSV)

[방법 C] SPVXSP 지수로 합성
  - CBOE/S&P Global에서 SPVXSP 일별 지수 다운로드
  - 이론가 수식으로 SVXY NAV 직접 합성: NAV(t) = NAV(t-1) × (1 - 0.5 × DR_SPVXSP)
```

### 2. SPVXSP 데이터 수집 방법

```python
# CBOE 공식 데이터 (유료/제한적)
# https://www.cboe.com/us/indices/dashboard/SPVXSP/

# S&P Global (Quandl 경유, 일부 무료)
# Quandl: CBOE/SPVXSP

# 대안: SVXY 실제 NAV 히스토리 (ProShares 공식)
# https://www.proshares.com/our-etfs/leveraged-and-inverse/svxy
# → "Historical NAV" 탭에서 CSV 다운로드 가능
```

### 3. 권장 백테스트 기간
