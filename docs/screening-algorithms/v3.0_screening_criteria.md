# 스크리닝 기준 상세 (스크리너 v3)

> 최종 업데이트: 2026-03-23 (v3 최적 파라미터 반영)

## 개요

**투자 철학:** 급등주를 피하고, 계단식으로 꾸준히 상승하는 주도주에 투자

**핵심 아이디어:** "강한 추세 + 꾸준한 상승 + 과열 아님 + 급등 아님"을 동시에 만족하는 종목만 선별

---

## 스크리닝 필터 (7개 조건, 모두 통과해야 후보 등록)

### 1. 추세 강도: ADX ≥ 20

"지금 추세가 존재하는가?"

- ADX(Average Directional Index)는 추세의 강도를 측정 (방향은 구분하지 않음)
- ADX < 20: 횡보/무추세 → 모멘텀 전략에 부적합
- ADX ≥ 20: 명확한 추세 존재
- 추세의 방향은 이동평균 정배열(조건 2)로 확인
- 기간: 14일
- v3 최적화: 기존 25에서 20으로 완화 → 유니버스 확장 시 후보 증가

### 2. 이동평균 정배열: 20MA > 50MA > 200MA

"구조적으로 상승 중인가?"

- 단기(20일) > 중기(50일) > 장기(200일) 이동평균 순서
- 이 정배열은 건강한 상승 추세의 구조적 신호
- 역배열(장기 > 단기)이면 하락 또는 횡보 중이므로 제외
- 최소 200일 데이터가 필요

### 3. RSI 범위: 50 ≤ RSI ≤ 77

"과매수도 과매도도 아닌 적정 구간인가?"

- RSI(Relative Strength Index): 최근 14일 상승/하락 비율
- RSI < 50: 모멘텀 약함 → 제외
- RSI > 77: 과열 상태 → 급등 후 조정 위험 → 제외
- 50~77이 "계단식 상승"의 적정 모멘텀 구간
- v1에서는 상한 70, v2에서 75, v3에서 77로 단계적 완화 (과매수 허용도 증가)

### 4. 거래량 급등 없음: 최근 20일 내 60일 평균의 3배 초과 없음

"비정상적 거래량 급등이 있었는가?"

- 최근 20일 중 하루라도 60일 평균 거래량의 3배를 초과하면 제외
- 거래량 급등 = 작전주, 뉴스 이벤트, 공시 → 지속성 낮음
- 꾸준한 거래량 유지 = 건강한 모멘텀의 신호

### 5. 단기 급등 없음: 최근 5일 내 단일 일봉 ±10% 초과 없음

"단기에 너무 많이 움직였는가?"

- 최근 5영업일 중 하루라도 종가 기준 ±10% 변동이 있으면 제외
- 하루 ±10% = 급등주/급락주 → 모멘텀이 아닌 이벤트 드리븐
- 계단식 상승은 하루 1~3% 수준으로 꾸준히 오르는 패턴

### 6. HH-HL 스윙 패턴 ≥ 2회 (60일)

"계단식 상승 패턴이 실제로 나타나는가?"

- **이 전략의 핵심 필터**
- Higher High(고점 갱신) + Higher Low(저점 올림)가 교대로 2번 이상 나타나야 함
- 스윙 포인트 감지: ±3봉 내 최고/최저점을 기준으로 판단 (v2에서 단순 비교 → 스윙 방식으로 개선)
- 최근 60영업일 내에서 측정
- 계단식 상승의 시각적 패턴을 수학적으로 정의한 조건
- v3 최적화: 기존 3회 → 2회로 완화 → 초기 상승 단계 종목도 포착 가능

### 7. 52주 고점 근접: 현재가 ≥ 52주 고점의 75%

"장기 상승 추세에서 크게 밀리지 않았는가?"

- 52주(252영업일) 고점 대비 25% 이상 하락한 종목은 제외
- 모멘텀 종목은 고점 근처에서 움직이는 특성
- v2에서 80% 기준으로 추가, v3에서 75%로 완화 (조정 후 반등 종목도 포함)

## 스크리닝 통과 후: 복합점수 산출

통과한 종목들을 순위화하기 위한 점수 산식:

```
복합점수 = ADX 정규화         × 0.4    ← 추세 강도가 가장 중요
         + 3개월 수익률 정규화 × 0.3    ← 최근 모멘텀
         + 섹터 초과수익률     × 0.2    ← 섹터 ETF 대비 얼마나 강한지
         + 거래량 안정성       × 0.1    ← 거래량이 꾸준한지
```

### 각 항목 설명

| 항목 | 가중치 | 계산 방법 | 의미 |
|---|---|---|---|
| ADX | 40% | minmax 정규화 | 추세가 강할수록 높은 점수 |
| 3M 수익률 | 30% | 63영업일 수익률, minmax | 최근 3개월 성과 |
| 섹터 초과수익 | 20% | 종목 3M수익률 - 섹터ETF 3M수익률 | 같은 섹터 내 상대 강도 |
| 거래량 안정성 | 10% | 1 / (거래량 CV + ε) | 변동계수 낮을수록 안정 |

### 섹터 ETF 매핑

```
Technology → XLK    Health Care → XLV    Financials → XLF
Consumer Disc → XLY  Industrials → XLI   Energy → XLE
Materials → XLB      Communication → XLC
```

## 포지션 구성

### 종목 선정
- 복합점수 **상위 10개** 종목

### 비중 배분 (score_capped)
- 점수 비례 배분 + 단일 종목 **최대 10%** 상한
- 상한 초과분은 나머지 종목에 재배분 (최대 20회 반복)
- 모든 비중 합계 = 100%
- v3 최적화: 기존 20% → 10%로 강화 (집중 리스크 감소, MDD 개선)

### 스톱로스 (ATR 동적)
```
스톱가 = 최근 20일 고점 - ATR(14) × 승수
```

| 전략 | ATR 승수 | 특성 |
|---|---|---|
| 공격적 | 1.5 | 좁은 스톱 → 빠른 손절 |
| 균형형 | 2.0 | 중간 |
| 보수적 | 2.5 | 넓은 스톱 → 노이즈 무시 |

변동성이 높은 종목은 ATR이 크므로 스톱이 자동으로 넓어지고,
변동성이 낮은 종목은 스톱이 좁아지는 자기 조절 메커니즘.
