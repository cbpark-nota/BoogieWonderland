# 시장 진입 시점 분석
## "저점 후 1개월 미이탈" 조건의 유효성 검증

> 작성일: 2026년 3월  
> 분석 대상: S&P500 코로나 급락(2020) · S&P500 금융위기(2009) · 나스닥 2022년 하락  
> 비교 기준: 골든크로스(50MA > 200MA) 진입 vs 저점 후 1개월 미이탈 진입

---

## 분석 배경

이동평균 추세 추종 전략(20MA > 50MA > 200MA 정배열)의 핵심 딜레마는 **진입 지연**이다.  
50MA가 200MA를 상회하는 골든크로스가 발생하는 시점은 실제 바닥 대비 평균 **3~6개월, +20~40% 상승 후**다.

이에 대한 대안으로 다음 조건을 검토한다.

> **진입 조건:** 시장이 반등하기 시작한 뒤, 1개월(약 20거래일) 동안 이전 저점 아래로 종가가 내려가지 않으면 진입 허용

## 바닥 유형별 특성

사례 분석 결과 시장 바닥은 크게 두 유형으로 나뉜다.

### V자 반등형 (2020, 2009)
- 정책 당국의 강력하고 신속한 개입이 동반
- 저점 이후 단 한 번의 재이탈 없이 추세적 상승 전환
- **1개월 미이탈 조건이 매우 유효**
- 조기 진입 시 골든크로스 대비 +14~15%p 우위

### 복합 바닥형 (2022)
- 매크로 악재(금리인상)가 장기간 지속
- 여러 차례 "가짜 바닥"을 형성하며 점진적 하락
- 1개월 조건 충족 후에도 재이탈 발생
- **스톱로스 없이 운용 시 손실 발생**

## 현재 시장(2026년 3월)에 대한 시사점

현재 SPY가 데드크로스(50MA < 200MA) 상태다.  
만약 시장이 반등하기 시작한다면, 이 분석에 따른 판단 기준은 다음과 같다.

1. **반등 시작 확인** — SPY가 최근 저점을 갱신하지 않고 3~5일 연속 상승
2. **1개월(20거래일) 대기** — 저점 아래로 종가가 내려가지 않으면 진입 조건 충족
3. **바닥 유형 판단** — V자형이면 신뢰도 높음, 복합 바닥 의심 시 소규모 진입 후 증량

## 알고리즘 반영 방안 (3단계 진입 구조)

```
1단계: 저점 후 1개월 미이탈 (진입 허용)
  → 관망 해제, 스크리닝 결과 신뢰
  → 포지션의 50%까지 진입 허용

2단계: SPY 50MA 기울기 하락→횡보→상승 전환 (진입 확대)
  → 이평선이 방향을 바꾸기 시작하는 시점
  → 포지션의 80%까지 확대

3단계: 골든크로스 확인 (전체 포지션 가동)
  → 50MA > 200MA
  → 100% 포지션 가동
```

### 스크리너 코드 반영 예시

```python
def check_entry_stage(spy_data: pd.DataFrame) -> dict:
    """
    진입 단계 판단
    Returns: {stage: 1|2|3|0, description: str, max_position_pct: float}
    """
    close  = spy_data["Close"].squeeze()
    ma50   = close.rolling(50).mean()
    ma200  = close.rolling(200).mean()

    # 최근 20거래일 저점
    low_20 = close.tail(20).min()
    low_21 = close.tail(21).min()  # 21일 전 저점

    # 1개월 미이탈 여부
    one_month_hold = low_20 >= low_21

    # 50MA 기울기
    ma50_slope = ma50.iloc[-1] - ma50.iloc[-5]

    # 골든크로스
    golden = ma50.iloc[-1] > ma200.iloc[-1]

    if golden:
        return {"stage": 3, "description": "골든크로스 — 전체 포지션 가동",
                "max_position_pct": 1.0}
    elif one_month_hold and ma50_slope > 0:
        return {"stage": 2, "description": "저점 유지 + 50MA 반등 — 80% 진입",
                "max_position_pct": 0.8}
    elif one_month_hold:
        return {"stage": 1, "description": "저점 유지 1개월 — 50% 진입",
                "max_position_pct": 0.5}
    else:
        return {"stage": 0, "description": "관망 — 조건 미충족",
                "max_position_pct": 0.0}
```

## 결론

| 조건 | 효과 | 주의사항 |
|---|---|---|
| 저점 후 1개월 미이탈 진입 | 골든크로스 대비 평균 3개월 일찍, +14~15%p 낮게 진입 | 복합 바닥형에서 위양성 가능 |
| 스톱로스 병행 | 위양성 신호 시 손실 제한 | ATR 기반 동적 스톱 권장 |
| 3단계 진입 구조 | 확신도에 따른 점진적 비중 확대 | 단계별 리밸런싱 필요 |

> **핵심 요약:**  
> V자 반등형 바닥에서는 이 조건이 골든크로스보다 훨씬 유리한 진입 시점을 제공한다.  
> 복합 바닥형에서는 ATR 스톱로스와 병행해야 손실을 제어할 수 있다.  
> 두 유형을 실시간으로 구별하기 어렵기 때문에, **항상 스톱로스와 함께 운용하는 것이 전제조건이다.**
