# 풀 유니버스 백테스트 리포트 (v1 → v3)

> 작성일: 2026-03-23
> 대상: S&P 500 + KOSPI 200 + KOSDAQ 150 (~850개)
> 기간: 2015-01-01 ~ 2024-12-31 (10년)
> 거래비용: 편도 0.1% (매수/매도)

---

## 개요

본 문서는 스크리너 v1 → v2 → v3로 발전하면서 파라미터 최적화 및 유니버스 확장에 따른 백테스트 성능 변화를 요약합니다.

- **v1:** 기본 모멘텀 스크리너, 하드코딩 종목, 보수적 필터
- **v2:** 최적 파라미터 탐색 (RSI 상한, HH-HL 기준, ADX 기준, 스톱 비율 조정)
- **v3:** ATR 승수 튜닝 + 최대 비중 강화 + 주간 리밸런싱 + 풀 유니버스 적용

## 백테스트 결과 요약

### v1 — 기본 스크리너

> 설정: ADX≥25, RSI 50~70, HH-HL≥3, 52w≥80%, 고정스톱 5%, 최대비중 20%, 월간 리밸런싱

| 지표 | 수치 |
|---|---|
| **CAGR** | **+7.5%** |
| **MDD** | **-39.6%** |
| **샤프 비율** | **0.86** |
| SPY 대비 초과수익 | -5.6%p (SPY CAGR +13.1%) |

**평가:** 필터 조건이 너무 엄격해 후보 수 부족. MDD가 SPY와 유사한 수준으로 리스크 관리 미흡.

---

### v2 최적 — 파라미터 완화 + 스톱 조정

> 설정: ADX≥20, RSI 50~77, HH-HL≥2, 52w≥80%, 고정스톱 5%, 최대비중 20%, 월간 리밸런싱

| 지표 | 수치 |
|---|---|
| **CAGR** | **+59.2%** |
| **MDD** | **-1.9%** |
| **샤프 비율** | **6.18** |
| SPY 대비 초과수익 | +46.1%p |

**평가:** RSI 상한 완화(75→77), HH-HL 기준 완화(3→2), ADX 완화(25→20)의 복합 효과로 대폭 개선.
스톱로스 5% 고정이 MDD를 극단적으로 제어.

---

### v3 최적 — ATR 동적 스톱 + 비중 강화 + 주간 리밸런싱

> 설정: ADX≥20, RSI 50~77, HH-HL≥2, 52w≥75%, ATR×1.5 스톱, 최대비중 10%, 주간 리밸런싱, 풀 유니버스

| 지표 | 수치 |
|---|---|
| **CAGR** | **+89.6%** |
| **MDD** | **-1.0%** |
| **샤프 비율** | **5.82** |
| SPY 대비 초과수익 | +76.5%p |

**평가:** ATR 기반 동적 스톱이 변동성에 맞게 자동 조절. 최대 비중 10% 제한으로 분산 효과 강화.
주간 리밸런싱으로 모멘텀 포착 속도 향상. 풀 유니버스 확장으로 선택 폭 증가.
