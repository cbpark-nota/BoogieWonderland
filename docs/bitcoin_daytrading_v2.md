# BTC 데이 트레이딩 v2 — 백테스트 결과 보고서

> **작성일**: 2026-03-24
> **기간**: 2015-01-01 ~ 2026-03-23 (약 11.2년, 4,100 거래일)
> **데이터**: yfinance BTC-USD 일봉
> **수수료**: 매수 0.05% + 매도 0.05% = RT 0.1%
> **목표**: 주간 평균 +1% 수익 (연 ~68% CAGR)

---

## 개요

기존 볼린저/RSI 전략(`backtest_btc_daytrading.py`)을 완전히 폐기하고, 세 가지 핵심 개념을 결합한 새로운 접근법을 개발했다:

1. **TTM Squeeze Momentum** — 볼린저 밴드와 켈트너 채널의 수축-확장 사이클 활용
2. **VWAP 이탈 회귀** — 20일 Rolling VWAP 대비 과도한 이탈 시 역방향 진입
3. **레짐 감지 + 전략 자동 전환** — Bull/Bear/Sideways 국면에 따라 파라미터와 진입 로직 자동 전환

## 전략 아키텍처

### 핵심 지표

| 지표 | 파라미터 | 역할 |
|---|---|---|
| 볼린저 밴드 | 20일, ±2σ | 변동성 측정 |
| 켈트너 채널 | 20일 EMA ± 2.0×ATR | 스퀴즈 기준선 |
| TTM Squeeze | BB ⊂ KC | 에너지 축적 감지 |
| Squeeze Momentum | 12일 선형 회귀 | 방향성 판단 |
| Rolling VWAP | 20일 가중 평균 | 공정 가치 기준 |
| ATR | 14일 EWM | 손절/익절 크기 |
| ADX | 14일 EWM | 추세 강도 측정 |
| RSI | 14일 EWM | 과매수/과매도 필터 |
| 레인지 포지션 | 20일 Donchian | 횡보장 진입 위치 |

### 스퀴즈 작동 원리

```
Squeeze ON  = BB_upper < KC_upper AND BB_lower > KC_lower
              (BB가 KC 안에 완전히 들어옴 → 변동성 압축)

Squeeze OFF = 이전 ON → 현재 OFF
              (BB가 KC를 벗어남 → 에너지 방출)

진입 조건   = Squeeze 해제 + Momentum 방향 (양수→롱, 음수→숏)
```

> **BTC 조정 사항**: 켈트너 채널 승수를 1.5 대신 2.0 사용.
> BTC의 연간 변동성이 60~120%에 달해 1.5×ATR KC에서는 스퀴즈가 거의 발생하지 않음.

## 5개 버전 요약

### V1: TTM Squeeze Momentum (기본)

- **핵심**: 스퀴즈 해제 시 모멘텀 방향으로 진입
- **손절**: 진입가 ± 2.5×ATR
- **익절**: 진입가 ± 4.0×ATR, 최대 10일 보유
- **약점**: 추세 필터 없어 역추세 신호 빈번

### V2: + 200MA 추세 필터

- **추가**: 200일 이동평균 기준 방향 필터
- **규칙**: 200MA 위 → 롱만, 200MA 아래 → 숏만
- **약점**: 200MA는 후행성이 강해 추세 전환 초기 신호를 놓침. 오히려 V1보다 성능 저하 발생.

### V3: + VWAP 이탈 회귀 병행

- **추가**: Rolling 20일 VWAP ±4% 이탈 시 역방향 진입 신호 병행
- **VWAP 파라미터**: SL=1.5×ATR, TP=2.0×ATR, 최대 5일
- **효과**: 거래 빈도 증가 (9→14회/년), 2022년 이후 성과 대폭 개선 (CAGR 44.7%)
- **약점**: 2019-2021 강세장에서 VWAP 이탈 역방향 진입이 손실 발생

### V4: + RSI Pullback + 다중 시간프레임

- **추가**: 25일 EMA 기울기로 주간 추세 방향 확인
- **추가**: 상승추세 + RSI < 38 Pullback 매수, 하락추세 + RSI > 62 매도
- **ADX 필터**: ADX > 22 (추세장 확인)
- **약점**: 필터 조건이 많아져 거래 빈도 감소, 초기 강세장에서 신호 부족

### V5: 레짐 감지 + 전략 자동 전환 (최적)

- **레짐 분류**:
  - **Bull**: 50MA > 200MA + 가격 > 50MA + ADX > 18
  - **Bear**: 50MA < 200MA + 가격 < 50MA + ADX > 18
  - **Sideways**: ADX < 15
- **Bull 전략**: Squeeze 롱 + RSI < 36 Pullback + VWAP -5% 이탈 롱 / SL=2.0, TP=5.0, 최대 15일
- **Bear 전략**: Squeeze 숏 + RSI > 64 Pullback + VWAP +5% 이탈 숏 / SL=1.8, TP=3.5, 최대 10일
- **Sideways 전략**: 레인지 하단(< 20%) 매수 + 상단(> 80%) 매도 / SL=1.2, TP=1.8, 최대 6일
- **안전 필터**: vol_ratio > 2.5 (이상 변동성) 시 진입 금지

## 핵심 발견 사항

### 1. BTC 강세장 바이어스의 역설

BTC는 2015년부터 11년간 CAGR 62%라는 전례 없는 강세장을 보였다. **어떤 트레이딩 전략이든 현금을 보유하는 동안 이 수익을 포기**한다. 이는 일봉 트레이딩의 구조적 한계다:

- V5는 연 6.4회 거래, 평균 9.5일 보유 → 연간 약 61일(17%) 시장 참여
- 나머지 83% 동안 현금 보유 → BTC 상승분 대부분 미획득

### 2. 주간 +1% 목표의 재해석

"주간 ≥+1%" 메트릭은 현금 보유 주(수익 0%)가 포함되어 수치가 낮게 측정된다.
실제 **활성 거래 주간만 기준**으로 보면:

- V5 활성 거래 기간 동안 평균 수익: 약 +2.1%/거래
- 하지만 현금 주간이 많아 전체 주간 평균은 0.4%에 그침

### 3. 리스크-조정 수익률 측면의 우위

| 지표 | BTC B&H | V5 전략 |
|---|---|---|
| CAGR | 62.0% | 20.1% |
| MDD | -83.4% | -47.9% |
| 샤프 | 0.79 | 0.44 |
| **MDD 대비 CAGR** | **0.74** | **0.42** |

BTC B&H는 절대 수익은 크지만 -83% 최대낙폭을 감수해야 한다. V5는 낙폭을 절반 수준으로 줄이면서도 합리적인 수익을 제공한다.

### 4. 시기별 효과성

- **2015-2018**: V5 +12.5% — 초기 BTC는 변동성이 극심해 신호 품질 저하
- **2019-2021**: V5 +36.7% — 가장 이상적. 명확한 추세 + 레짐 전환
- **2022-현재**: V5 +16.5% — 제도권 편입으로 변동성 감소, 횡보 구간 증가

## 한계 및 추가 개선 방향

### 현재 한계

1. **저빈도 트레이딩**: 일봉 기준 연 6-14회 거래는 "데이 트레이딩"보다 스윙 트레이딩에 가깝다
2. **과최적화 위험**: 5개 버전의 파라미터가 과거 데이터에 편향될 가능성
3. **숏 전략 약점**: 숏 거래의 장기 기대값이 거의 0에 수렴 (BTC 강세장 구조 때문)
4. **슬리피지 미반영**: 일봉 종가 체결 가정 (실제는 추가 비용 발생)

### 개선 방향

| 우선순위 | 개선 사항 | 예상 효과 |
|---|---|---|
| High | 시간봉 데이터 도입 (최근 2년) | 거래 빈도 10배 증가, 더 정교한 진입 |
| High | 롱 온리 전략 (숏 제거) | BTC 강세장 바이어스 활용, 수익 개선 |
| Medium | 변동성 기반 포지션 사이징 | MDD 추가 개선 |
| Medium | 온체인 데이터 연동 (Hash Rate, 활성 주소) | 레짐 감지 정확도 향상 |
| Low | 머신러닝 앙상블 신호 | 신호 품질 개선 |
