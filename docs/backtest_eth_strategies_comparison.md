## 2. B안 알고리즘 결정 근거

CCF 분석 결과 모든 구간 (전체/Bull/Bear)에서 양수 lag 최댓값이 0봉 → **lag 0 트레이딩** 채택.

**B안 정의**:
1. BTC 4h 데이터에 strategy_v1~v10을 실행 → BTC position 시퀀스 도출
2. 같은 봉(t=0)의 ETH 가격에 동일 position을 적용 → ETH P&L 계산
3. 매도 조건(SL/TP/MH)은 BTC 가격/ATR 기준 (각 vN strategy 내부 그대로)
4. 의미: BTC strategy 신호의 ETH 카피 트레이딩

Bear 게이트 별도 추가는 하지 않음 — V8/V9/V10이 이미 BTC bull regime일 때만 진입하도록 설계되어 있음.

## 6. 핵심 인사이트

1. **B안이 A안을 압도**: 모든 v1~v10에서 B안의 CAGR이 A안보다 동일하거나 높음. 특히 v10은 A안 +23.4% → B안 +45.0% (≈2배). MDD도 -49.6% → -33.2% 로 개선.

2. **ETH 단독 신호의 한계**: A안에서는 v1~v6이 모두 손실 (CAGR -14% ~ -26%). v8 롱온리부터 흑자 전환. ETH 4h 가격 변동성이 BTC보다 높아 SL/TP 같은 ATR 기반 청산이 자주 트리거되어 휩소(whipsaw) 손실 누적.

3. **BTC 신호의 ETH에 대한 강한 예측력**: Granger BTC→ETH 최소 p=0.0003154로 매우 유의. ETH→BTC는 약함 → BTC가 정보 우위. BTC strategy의 SL/TP가 BTC 가격/ATR로 작동하지만 ETH 가격에 적용해도 잘 작동하는 이유: BTC가 ETH 추세를 안정적으로 잡아주기 때문.

4. **B안 V10이 ETH B&H를 큰 폭 상회**: ETH B&H CAGR +23.8%, MDD -81.1%. B안 V10 CAGR +45.0%, MDD -33.2%. 즉 ETH를 그냥 들고있는 것보다 BTC 신호로 단속적 진입/청산하면 동일 자산에서 ~2배 수익 + 절반 이하 MDD.

5. **B안 V10이 BTC V10보다도 우수**: BTC V10 CAGR +32.1%, B안 V10 +45.0%. ETH가 BTC 신호의 변동성을 증폭하기 때문 (ETH 수익률 std ≈ BTC × 1.2~1.4). 단 MDD도 함께 증폭됨에 유의.

## 8. 한계 및 주의사항

- 백테스트 기간이 2021~2026 (≈5년)으로 1~2 사이클만 포함 → 다음 사이클에서 동일 성과 보장 X.
- B안은 BTC 가격/ATR 기준으로 SL/TP를 트리거하므로 BTC가 횡보하고 ETH만 급변하는 구간에서 청산이 늦어질 수 있음.
- 슬리피지/수수료는 RT 0.1%로 가정 (Binance VIP 0~3 수준). 시장가/대량 주문 시 추가 비용 가능.
- 모든 결과는 hindsight optimization 위험을 내재 (특히 V10은 'V9 + 파라미터 완화' 구조).
