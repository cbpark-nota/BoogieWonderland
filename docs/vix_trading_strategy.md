# VIX 매매 전략 가이드

**작성일:** 2026-04-11  
**버전:** 1.0  
**목적:** VIX 급등 시 SVXY/SVIX ETF 저가 매수 전략 — 스크리닝 앱 strategy 페이지 노출용

---

## 1. 전략 개요

VIX(공포지수)가 급등하는 시장 혼란 구간에서 **SVXY / SVIX ETF를 미리 낮은 가격에 지정가 매수**하여, VIX가 평균으로 회귀할 때 수익을 실현하는 전략이다.

**핵심 로직:**
- VIX는 강한 평균 회귀(mean reversion) 성질을 지님
- VIX 급등 → SVXY/SVIX 급락 → 지정가 매수 체결
- VIX 정상화 → 선물 지수 콘탱고(contango) 구조 덕분에 ETF 빠른 회복
- 스크리닝 앱의 **VIX 매매 탭**이 시나리오별 이론가 테이블을 자동 계산

**매매 방식:** 미리 낮은 가격에 지정가 주문을 배치해두고 체결을 기다리는 방식 (장중 모니터링 최소화)

## 2. ETF 사양

### 2.1 SVXY (ProShares Short VIX Short-Term Futures ETF)

| 항목 | 내용 |
|------|------|
| 운용사 | ProShares |
| 추종 지수 | S&P 500 VIX Short-Term Futures Index (SPVXSP) |
| 추종 배율 | **-0.5x** (일간) |
| 비용비율 | 0.95% |
| NAV 산정 시각 | 16:15 ET (VIX 선물 정산 기준) |
| 이론가 수식 | `NAV(t) = NAV(t-1) × (1 - 0.5 × R)` |

> R = SPVXSP 지수의 일간 변동률 (소수 표현, 예: +20% → R = 0.20)

### 2.2 SVIX (Volatility Shares -1x Short VIX Futures ETF)

| 항목 | 내용 |
|------|------|
| 운용사 | Volatility Shares |
| 추종 지수 | Short VIX Futures Index (SHORTVOL) |
| 추종 배율 | **-1x** (일간) |
| 비용비율 | 1.35% |
| NAV 산정 | TWAP 기반 (장 마감 전 15분 시간가중평균) |
| 이론가 수식 | `NAV(t) = NAV(t-1) × (1 - R)` |
| 출시일 | 2022년 |

### 2.3 SVXY vs SVIX 비교

| 항목 | SVXY | SVIX |
|------|------|------|
| 배율 | -0.5x | -1x |
| 추종 지수 | SPVXSP | SHORTVOL |
| VIX 선물 지수 +100% 시 | NAV 50% 보존 | 이론상 NAV = 0 |
| VIX 선물 지수 +50% 시 | -25% | -50% |
| 경로 의존성 영향 | 상대적으로 작음 | 상대적으로 큼 |
| 전멸 리스크 | 없음 (-0.5x) | 이론상 가능 (-1x) |

**권장 배분:** SVXY 60% + SVIX 40%  
SVIX 비중을 높이면 수익률은 높아지나, 극단적 VIX 급등 시 손실이 기하급수적으로 커짐

## 3. VIX 선물 지수 구조 (핵심)

### 3.1 SPVXSP / SHORTVOL은 "지수"이지 선물 자체가 아니다

- **시작값:** 2005년 12월 20일 기준값 100,000에서 출발, 매일 누적 수익률 반영
- **현재값(2026-04 기준):** SPVXSP ≈ 6,162 / SHORTVOL ≈ 1,285
- → **VIX 절대값(예: 20, 30)과 직접 비교 불가**

### 3.2 연속 롤링 지수 구조

1개월물 + 2개월물 VIX 선물을 매일 롤오버 → **항상 만기까지 약 1개월 유지**하는 연속 롤링 지수

```
1개월물 가중치 = dr / dt
2개월물 가중치 = 1 - (dr / dt)
```
- `dt`: 현재 롤 기간 총 영업일 수
- `dr`: 다음 결제일까지 잔여 영업일 수

**결과:** contango 환경에서 선물 롤오버 시 손실 누적 → 장기 보유 시 지수값 하락 → 이것이 SVXY/SVIX의 구조적 수익 원천

### 3.3 이론가 계산에 필요한 것은 지수의 "일간 변동률(R)"

```
일간 변동률 DR(t) = [w1 × F1(t)/F1(t-1)] + [w2 × F2(t)/F2(t-1)] - 1
```

- `F1`, `F2`: 1개월물, 2개월물 VIX 선물 가격
- SPVXSP의 절대값(6,162)이 아닌, **전일 대비 변동률**이 이론가 계산 입력값

**예시:** SPVXSP 어제 6,000 → 오늘 6,162 → R = +2.7%  
→ SVXY 이론가 = 전일 NAV × (1 - 0.5 × 0.027) = 전일 NAV × 0.9865

## 4. VIX 현물 → 선물 지수 변환 (근사)

VIX 현물이 +10% 올라도 선물 지수가 정확히 +10%로 움직이지는 않는다.

| VIX 현물 변동 | 선물 지수 변동 (경험적) | 비고 |
|-------------|---------------------|------|
| +10% | +5%~+7% | 정규 상황 |
| +50% | +25%~+35% | 중간 이벤트 |
| +100% | +50%~+70% | 극단적 급등 |

**이유:** VIX 선물은 만기에 따라 현물보다 둔하게 반응 (보통 현물 변동의 약 **50~70%** 반영)

**스크리닝 앱의 VIX 매매 탭 처리:**
- 현재 VIX 현물 변동률을 R로 사용 (근사값)
- 정확한 계산에는 SPVXSP/SHORTVOL 실제 변동률 필요 (yfinance 미지원)

## 5. 경로 의존성

일간 리밸런싱으로 인해 **같은 누적 변동이라도 경로에 따라 이론가가 달라진다.**

**예시: VIX 선물 지수 2일간 총 +44% 상승 (기준: SVXY NAV $46.05)**

| 경로 | 1일차 | 2일차 | SVXY 이론가 |
|------|-------|-------|-----------|
| A: 균등 분산 | +20% | +20% | $37.30 |
| B: 집중 급등 | +40% | +2.86% | $36.31 |

→ **단일일 급등이 매수자에게 가장 유리한 가격(하한)을 제공**  
→ 분산 급등 시 ETF 가격이 더 높아짐 (리밸런싱으로 포지션 축소 효과)

**실전 적용:**
- 지정가 매수는 **단일일 이론가(하한)** 기준으로 설정
- 체결 안 되면 다중일 이론가(상한)를 참고하여 가격 상향 재주문

## 6. 매매 전략

### 6.1 계단식 지정가 매수

VIX 선물 지수 변동 구간별로 나누어 미리 지정가 주문 배치:

| VIX 선물 지수 변동(R) | VIX 수준 (근사) | 매수 비중 |
|----------------------|----------------|---------|
| +20% | ~24 | 10% |
| +30% | ~26 | 10% |
| +40% | ~28 | 15% |
| +50% | ~30 | 15% |
| +60% | ~32 | 15% |
| +70% | ~34 | 15% |
| +80% | ~36 | 10% |
| +90% | ~38 | 5% |
| +100% | ~40 | 5% |

중간 구간(+40%~+70%)에 더 많은 비중 — 역사적으로 가장 빈번한 급등 고점 영역

### 6.2 ETF 배분

- **SVXY 60%** + **SVIX 40%** (권장)
- 예비자금 **30%** 별도 보유 → VIX 예상 상단 돌파 시 추가 매수용

### 6.3 매도 조건

| 매도 유형 | 조건 |
|----------|------|
| 1단계 이익실현 | VIX 임계값 하회 시 1/3 매도 |
| 2단계 이익실현 | VIX 평균 수준 복귀 시 1/3 추가 매도 |
| 3단계 (콘탱고 수익) | 나머지 1/3 보유 |
| 손절 | 투입 원금 대비 -50% 도달 시 전량 매도 |

**매도 기준: VIX 20 이하 회복 시** 단계적 청산 시작

### 6.4 총 투입 한도

```
최대 투입 금액 = 총 투자자산의 5%~15%
  SVXY 투입: 최대 투입의 60%
  SVIX 투입: 최대 투입의 40%
```

## 8. 주의사항

### 8.1 SVXY 이력 변경
- **2018-02-27 이전:** -1x 배율 운용 (Volmageddon 이후 -0.5x로 변경)
- 액면병합 이력 있음 → 2018년 이전 가격 데이터 직접 연결 불가
- 백테스트는 **2018-03 이후 데이터**만 사용 권장

### 8.2 데이터 한계
- SPVXSP / SHORTVOL 실시간 데이터: **yfinance 미지원**
- 스크리닝 앱은 VIX 현물 변동률을 근사값으로 사용
- 정밀 이론가 계산은 CBOE/ProShares 공식 데이터 필요

### 8.3 VIX 현물 vs 선물 지수 괴리
- VIX 현물 변동률 ≠ SPVXSP 변동률
- 실제 선물 지수는 현물의 **50~70%** 수준으로 반응
- 이론가 테이블은 근사값이므로 실제 매수가 설정 시 여유분 반영 권장

### 8.4 SVIX 전멸 리스크
- VIX 선물 지수 단일일 **+100% 이상 급등** 시 이론상 NAV = 0
- 2018년 XIV(SVIX 전신 격) 단일일 -96% 하락 사례 실존
- SVIX 투입 금액은 **전액 손실 감수 가능한 수준**으로 엄격히 제한
