## 핵심 발견 사항

### 1. 2021+ 구간에서 V4가 레거시 전략 최강

V5 (레짐 감지)는 전체 2015+ 기간 기준으로는 최적이었으나,
2021+ 구간에서는 **V4 (RSI Pullback + 다중 시간프레임)**이 훨씬 우수하다.

- V4: CAGR 21.7%, MDD -22.6%, 샤프 0.56
- V5: CAGR 9.6%, MDD -24.9%, 샤프 0.17

2021+ 시장에서 레짐 감지의 ADX 기준이 맞지 않아 "neutral" 상태가 너무 많아졌다.

### 2. V7 (BB Break)가 신규 전략 최강

2021+ 최적화 5개 버전 중 **V7 (BB Break 추가)**이 가장 우수했다:
- CAGR 14.5%로 신규 버전 1위
- 11회/년의 적절한 거래 빈도
- 2023–2024 강세장에서 CAGR 25.4% 달성

### 3. V10 과적합 문제

V10은 파라미터를 너무 완화(ADX 13, RSI 48, VWAP -2%)한 결과 잡음 신호가 많아졌다:
- 전체 CAGR 4.1% (V6의 절반 이하)
- OOS(2025+) -15.0% (가장 나쁨)
- 과적합의 교과서적 사례

## 한계 및 추가 개선 방향

### 현재 한계

1. **저빈도 트레이딩**: 일봉 11회/년은 여전히 스윙 트레이딩 수준
2. **현금 보유 기간**: 70%+ 현금 → 주간 평균 수익률 저하
3. **2025 OOS 성과 부진**: 전략 모두 음수 CAGR (BTC 하락 국면)
4. **숏 전략의 한계**: BTC 강세 바이어스로 숏 거래 기대값 ≈ 0

### 개선 방향 (우선순위)

| 우선순위 | 개선 사항 | 예상 효과 |
|---|---|---|
| **High** | 시간봉 데이터 도입 (4시간봉) | 거래 빈도 5–10배 증가 |
| **High** | V4 (RSI Pullback) 파라미터 2021+ 재조율 | 검증된 전략 강화 |
| **High** | V7 + V8 하이브리드 (BB Break 롱온리) | 최고 성능 조합 |
| Medium | 반감기 사이클 필터 (4년 주기) | 레짐 감지 개선 |
| Medium | 변동성 기반 동적 포지션 사이징 | MDD 추가 개선 |
| Low | 온체인 데이터 (Hash Rate, 활성 주소) | 레짐 감지 정확도 향상 |

## 결론

**주간 +1% 목표 달성 여부**: 일봉 트레이딩 전략으로는 미달성 (V7 최고 16.1%).

**2021+ 구간 최종 권고 전략**:

| 목적 | 권고 전략 | 이유 |
|---|---|---|
| 최고 CAGR | V4 레거시 (21.7%) | 2021+ 검증 최강 |
| 신규 최고 CAGR | V7 BB Break (14.5%) | 거래 빈도 11회/년 |
| 최저 MDD | V8 롱온리 (MDD -24.5%) | 안정적 하방 보호 |
| OOS 안정성 | V7 BB Break (-4.6%) | 2025+ 최소 손실 |

**실전 적용 권고**:
1. **V7 (BB Break) + 롱온리 하이브리드**를 기본 전략으로 사용
2. Bear 레짐에서는 현금 보유 (V8의 핵심 통찰)
3. 시간봉 데이터로 확장하면 거래 빈도가 5–10배 증가하여 주간 +1% 목표 달성 가능
4. 2× 레버리지 적용 시 V7 기준 약 29% CAGR (MDD ~-55%) → 주간 +1% 수준

**과적합 경고**: V10 사례에서 보듯, 파라미터 완화만으로는 성과 개선이 없다.
핵심은 신호의 **질(Quality)** 유지 + **빈도(Frequency)** 균형이다.
