# 적응형 전략 백테스트 결과

## 전략 개요

시장 국면(강세/보통/약세)을 자동 감지하여 ATR 승수와 리밸런싱 주기를 동적 전환하는 전략.

### 4가지 전략 프리셋

| 전략 | ATR 승수 | 리밸런싱 | 성격 |
|---|---|---|---|
| 공격적 | 2.0 | 주간 | 좁은 스톱, 빠른 교체 |
| 균형형 | 2.5 | 격주 | 중간 스톱, 적당한 교체 |
| 보수적 | 3.5 | 월간 | 넓은 스톱, 느린 교체 |
| 적응형 | 동적 | 동적 | 국면별 위 3개를 자동 전환 |

### 국면 판별 로직 (3계층 복합)

```
Layer 1 (추세): SPY 50MA vs 200MA gap
  gap > 5%  → 공격적
  gap 0~5%  → 균형형
  gap < 0%  → 보수적

Layer 2 (모멘텀): RSI + MA 기울기로 1단계 다운그레이드
  RSI < 35 또는 20MA 기울기 < -3% → 한 단계 보수적

Layer 3 (리스크): 즉시 보수적 전환 트리거
  주간 수익률 < -5% (급락)
  200MA 하회 + RSI < 40 (복합 조건)
  변동성 상위 10% + 하락 중

비대칭 전환:
  공격→보수: 즉시 (1주 내)
  보수→공격: 1주 확인 후 전환
```

## 핵심 인사이트

1. **국면 판별 v2가 v1 대비 개선**: 풀사이클에서 CAGR +1.6%p, MDD 6.1%p 개선
2. **공격적 고정이 CAGR 최고**: 이 유니버스(대형 성장주)가 강세장 편향
3. **보수적이 위험 대비 효율 최고**: 샤프 비율 4.28~5.78로 일관되게 최고
4. **적응형의 가치**: 예측 불가능한 미래 하락장에서의 방어력. 특히 GFC 포함 시 MDD -11% vs 고정 전략들의 -7~-8.5%이지만, SPY의 -55.2% 대비 압도적 방어
