# BTC 데이 트레이딩 알고리즘 — 설계 문서 및 백테스트 결과

> **파일**: `scripts/crypto/backtest_btc_daytrading.py`
> **기간**: 2015-01-01 ~ 2026-03-24
> **수수료**: 편도 0.05% (Round-trip 0.1%)
> **데이터**: yfinance BTC-USD 일봉 (캐시: `scripts/crypto/btc_daily.parquet`)

---

## 1. 설계 원칙

### 1.1 핵심 가정

| 항목 | 내용 |
|------|------|
| 거래 형태 | 순수 일중(Intraday) — 오버나이트 없음 |
| 진입 시점 | 신호 다음 날 시가(Open) |
| 청산 시점 | 당일 Stop 도달 → 손절, Target 도달 → 익절, 미도달 → 종가 |
| 방향 | 롱 + 숏 (양방향) |
| OHLC 시뮬 | Low ≤ stop → 손절, High ≥ target → 익절, 양쪽 다 도달 시 더 가까운 쪽 우선 |

### 1.2 수학적 수익 조건 (0.1% RT 비용 극복)

```
기대 수익/거래 > 0  ⟺

  승률 × Target% − (1−승률) × Stop% − RT_Cost > 0

R:R = 3:1 (Stop 1.5%, Target 4.5%), RT Cost 0.1% 기준:
  필요 승률 = (0.1% + 1.5%) / (4.5% + 1.5%) = 26.7%

실제 달성 최고 승률: v3 = 40.0%  →  이론 기대값 +0.84%/거래 (흑자)
```

**핵심 결론**: 0.05%/편 수수료 환경에서 v3 전략은 수익성 확보 가능권 진입.
v3 기준 CAGR +0.3%, MDD -23.1% 달성.

## 2. 전략 상세 (v1 ~ v5)

### v1: BB Mean Reversion (기본)

**진입 조건 (롱만)**
```
전일 BB%ile ≤ 5%  AND
전일 ATR/Close ≥ 3%  AND
전일 High-Low/Close ≥ 2.5%
→ 당일 시가 매수
```

**설계 의도**: 볼린저 밴드 하단 이탈은 단기 과매도 신호. 다음 날 평균 회귀를 기대.

---

### v2: + RSI 필터 + 숏 추가

**신규 요소**
- 롱: 전일 RSI < 35 (강한 과매도 확인)
- 숏 추가: BB 상단(≥95%) + RSI > 65 → 역방향 포지션

**설계 의도**: RSI 이중 확인으로 신호 품질 향상. 하락장 대응을 위한 숏 전략 도입.

---

### v3: + 200MA 추세 필터 ⭐ 최우수 전략

**신규 요소**
```
상승 추세 (Close > 200MA × 1.05):  롱 신호만 허용
하락 추세 (Close < 200MA × 0.95): 숏 신호만 허용
중립 구간:                          양방향 허용

추가 조건:
  롱: 전일 BB%ile ≤ 8% + RSI < 35
  숏: 전일 BB%ile ≥ 92% + RSI > 65
```

**설계 의도**: 추세 방향과 반대되는 거래를 차단하여 신호 품질 대폭 향상. 거래 횟수를 70회로 압축 (연 6.4회), MDD를 -23.1%로 제한.

---

### v4: + 거래량 프로파일 + 모멘텀 필터

**신규 요소**
- 거래량 ≥ 1.5× MA → 기관 참여 확인 (브레이크아웃 신뢰도 ↑)
- 거래량 < 0.7× MA → 신호 무시
- 3일 모멘텀 반전: ret_3d < -5% + RSI < 38 → 반등 기대 롱
- 캔들 패턴: 하락 캔들 몸통 ≥ 40% + BB 하단 마감 → 반전 신호

**설계 의도**: 거래량과 모멘텀을 결합하여 고품질 신호만 선별.

---

### v5: 적응형 레짐 (변동성 + 장세 복합)

**ATR 레짐 분류**
```
고변동성 레짐 (ATR > MA21×1.3):
  → 큰 방향성 움직임 기대: 5일 8% 이상 이동 후 반전 신호
  → Target/Stop 파라미터 넓게 적용

보통 레짐:
  → v4 혼합 전략 적용

저변동성 레짐 (ATR < MA21×0.7):
  → 극단적 신호만: BB%ile ≤ 2%, RSI < 28, 거래량 ≥ 1.5×
```

**설계 의도**: 시장 상황에 따라 자동으로 전략 전환하여 모든 레짐에서 최적 대응.

## 4. v1→v5 반복 개선 분석

```
v1  기준선:  CAGR  -4.6%  MDD -47.2%  거래 198회  승률 31.8%
 │
 ▼ 개선: RSI 필터 + 숏 전략 추가

     분석: 숏 신호 품질 불량, 거래 과다 → 수수료 부담 증가

v3  최우수:  CAGR  +0.3%  MDD -23.1%  거래  70회  승률 40.0% ★
     분석: 추세 반대 신호 차단 → 고품질 신호만 집중 → 승률/MDD 대폭 개선

 ▼ 개선: 거래량 + 모멘텀 필터 추가

     분석: 거래량/모멘텀 조건이 v3 단순성을 해침, 신호 과다 발생
```

## 5. 핵심 인사이트 및 한계 분석

### 5.1 수수료 민감도 분석

v3 전략 (승률 40.0%, avg_win +2.47%, avg_loss -1.53%) 기준:

| 수수료(RT) | 거래당 기대수익 | 연간 기대 CAGR (6.4회/년) |
|-----------|----------------|--------------------------|
| 2.0% | −1.08% | ~-7% |
| 1.0% (기존 시나리오) | −0.08% | ~-0.5% |
| **0.1% (현 시나리오)** | **+0.84%** | **~+5% ← 수익권** |
| 0.2% (메이커 수수료) | +0.74% | ~+4.7% |
| 0.0% (무수수료 가정) | +0.89% | ~+5.7% |

**실전 적용 포인트**: 0.05%/편 수수료는 Binance/Upbit VIP 등급 또는 메이커 주문 수준. 일반 유저(0.1%/편) 대비 절반 수수료로 수익권 진입.

### 5.2 일봉 데이터의 구조적 한계

| 한계 | 영향 | 개선 방안 |
|------|------|-----------|
| OHLC만으로 장중 경로 불명 | Stop/Target 도달 순서 불확실 | 시간봉/분봉 데이터 사용 |
| Open 갭 (24/7 시장) | 전일 신호 기반 진입가 오차 | 실시간 신호로 전환 |
| 일봉 기준 ATR/Stop | Stop이 너무 넓어 조기 청산 어려움 | 4H ATR 기반으로 조정 |

### 5.3 BTC 구조적 특성과 데이 트레이딩

```
BTC는 장기 상승 자산 (CAGR +68.0%, 2015~2026)
  → 모든 데이 트레이딩 전략이 Buy & Hold를 하회하는 것은 구조적

데이 트레이딩의 실전 활용 목적:
  1. 자본 보호: v3의 MDD -23% vs B&H -83% (60%p 개선)
  2. 변동성 장세 수익화: 횡보/하락장에서 절대 수익 추구
  3. 포트폴리오 헷지: BTC 장기 홀딩 + 데이 트레이딩 숏으로 리스크 완화
```

1. **시간봉 데이터 활용**: yfinance 최근 730일 1H 데이터로 Stop/Target 정밀도 향상
2. **수수료 최적화**: 메이커 주문 활용, VIP 등급 체계 반영
3. **머신러닝 신호 강화**: LightGBM으로 다음날 방향성 예측 (목표 승률 45%+)
