## 2. VIX 선물 지수 구조

### 2.1 S&P 500 VIX Short-Term Futures Index (SPVXSP)

SPVXSP는 1개월물과 2개월물 VIX 선물을 일간 롤링하여 가중평균 만기가 항상 1개월이 되도록 유지하는 지수이다.

**롤링 구조:**

롤 기간(Roll Period)은 해당 월의 CBOE VIX 선물 결제일(Settlement Date) 전 화요일 장 마감 후부터 다음 달 VIX 선물 결제일 전 화요일까지이다. VIX 선물 결제일은 S&P 500 옵션 만기 30일 전의 수요일이다.

**핵심 변수:**

- `dt`: 현재 롤 기간의 총 영업일 수 (현재 결제일 포함, 다음 결제일 미포함)
- `dr`: 현재일 다음 영업일부터 다음 결제일 전일까지의 잔여 영업일 수

**일간 가중치 계산:**

```
1개월물 가중치 = dr / dt
2개월물 가중치 = 1 - (dr / dt)
```

롤 기간이 진행됨에 따라 1개월물 가중치는 점차 감소하고 2개월물 가중치는 증가하여, 매일 일정 비율씩 근월물에서 차월물로 전환된다.

**Excess Return 지수 일간 수익률:**

```
SPVXSP_ER(t) = SPVXSP_ER(t-1) × (1 + DR(t))
```

여기서 일간 수익률 DR(t)는:

```
DR(t) = [w1(t-1) × F1(t)/F1(t-1)] + [w2(t-1) × F2(t)/F2(t-1)] - 1
```

- `w1(t-1)`: 전일 기준 1개월물 가중치 = dr/(dt)
- `w2(t-1)`: 전일 기준 2개월물 가중치 = 1 - w1
- `F1(t)`: t일의 1개월물 VIX 선물 정산가
- `F2(t)`: t일의 2개월물 VIX 선물 정산가

### 2.2 SHORTVOL 지수 (SVIX용)

SHORTVOL 지수는 SPVXSP와 동일한 1개월/2개월 VIX 선물 롤링 구조를 사용하지만, 정산가 산출 방식이 다르다.

- SPVXSP: VIX 선물 최종 정산가(종가) 사용
- SHORTVOL: 장 마감 전 15분간의 TWAP 사용

이 차이로 인해 같은 날이라도 SPVXSP와 SHORTVOL의 일간 수익률은 미세하게 다를 수 있다.

## 3. 이론가 계산 알고리즘

### 3.1 핵심 원리

SVXY와 SVIX의 이론가(괴리율 0%)는 각 ETF의 전일 NAV에 해당일의 추종 지수 수익률을 배율만큼 적용하여 계산한다. 이는 "일간 리밸런싱" 구조에서 비롯된다.

### 3.2 SVXY 이론가 수식

```
SVXY_NAV(t) = SVXY_NAV(t-1) × [1 + (-0.5) × DR_SPVXSP(t)]
```

여기서:
- `SVXY_NAV(t-1)`: 전일 SVXY NAV (16:15 ET 기준)
- `DR_SPVXSP(t)`: 당일 SPVXSP 지수의 일간 수익률
- `-0.5`: SVXY의 추종 배율

전개하면:

```
SVXY_NAV(t) = SVXY_NAV(t-1) × [1 - 0.5 × DR_SPVXSP(t)]
```

### 3.3 SVIX 이론가 수식

```
SVIX_NAV(t) = SVIX_NAV(t-1) × [1 + (-1) × DR_SHORTVOL(t)]
```

전개하면:

```
SVIX_NAV(t) = SVIX_NAV(t-1) × [1 - DR_SHORTVOL(t)]
```

### 3.4 VIX 선물 지수 수익률로부터 이론가 역산

실전에서는 "VIX 선물 지수가 X% 움직이면 SVXY/SVIX 이론가는 얼마인가?"를 계산해야 한다.

**단일일 시나리오 (가장 단순한 경우):**

VIX 선물 지수가 전일 대비 R% 변동했다고 가정하면:

```
SVXY 이론가 = 전일 NAV × (1 - 0.5 × R)
SVIX 이론가 = 전일 NAV × (1 - R)
```

여기서 R은 소수 표현 (예: 20% 상승 = 0.20)

**예시 계산 (기준일: 2026-04-07):**

기준 데이터:
- SVXY NAV: $46.05
- SVIX NAV: $16.04
- SPVXSP: 약 5,307

| VIX 선물 지수 변동(R) | SPVXSP 지수값 | SVXY 이론가 | SVIX 이론가 |
|----------------------|--------------|------------|------------|
| +10% | 5,838 | $43.75 | $14.44 |
| +20% | 6,368 | $41.45 | $12.83 |
| +30% | 6,899 | $39.14 | $11.23 |
| +40% | 7,430 | $36.84 | $9.62 |
| +50% | 7,961 | $34.54 | $8.02 |
| +60% | 8,491 | $32.23 | $6.42 |
| +70% | 9,022 | $29.93 | $4.81 |
| +80% | 9,553 | $27.63 | $3.21 |
| +90% | 10,083 | $25.33 | $1.60 |
| +100% | 10,614 | $23.02 | $0.00 |

**핵심 관찰:** SVIX는 VIX 선물 지수가 +100% 되면 이론상 NAV가 0이 된다. SVXY는 -0.5x이므로 +100%에서도 NAV의 50%는 보존된다.

### 3.5 다중일 시나리오 (경로 의존성)

일간 리밸런싱 ETF는 다중일에 걸쳐 단순 배율을 적용할 수 없다. 경로 의존성(path dependency)이 존재한다.

**N일간의 이론가:**

```
SVXY_NAV(t+N) = SVXY_NAV(t) × 연산곱(i=1 to N) [1 - 0.5 × R(i)]
SVIX_NAV(t+N) = SVIX_NAV(t) × 연산곱(i=1 to N) [1 - R(i)]
```

여기서 R(i)는 i번째 날의 VIX 선물 지수 일간 수익률이다.

**경로 의존성 예시:**

VIX 선물 지수가 2일에 걸쳐 총 +44% 상승하는 두 가지 경로를 비교한다.

경로 A: +20% 후 +20% (연속 균등 상승)
```
SVXY: $46.05 × (1-0.10) × (1-0.10) = $46.05 × 0.81 = $37.30
SVIX: $16.04 × (1-0.20) × (1-0.20) = $16.04 × 0.64 = $10.27
```

경로 B: +40% 후 +2.86% (급등 후 소폭 상승)
```
SVXY: $46.05 × (1-0.20) × (1-0.0143) = $46.05 × 0.7886 = $36.31
SVIX: $16.04 × (1-0.40) × (1-0.0286) = $16.04 × 0.5829 = $9.35
```

동일한 누적 변동이라도 경로에 따라 이론가가 달라진다. 변동성이 클수록(큰 폭의 일간 변동) ETF에 더 불리하다. 이 효과는 SVIX(-1x)가 SVXY(-0.5x)보다 훨씬 크다.

### 3.6 특정 VIX 선물 지수 목표값에서의 이론가 계산

실전에서는 "SPVXSP가 X 값이 되면 SVXY는 얼마인가?"를 알고 싶다. 이때 경로를 가정해야 한다.

**단일일 급등 가정 (ETF 가격 하한 — 매수자에게 최적):**

VIX 선물 지수의 전체 변동이 하루에 집중되면, ETF는 리밸런싱 없이 최대 폭의 손실을 입으므로 이론가가 가장 낮다.

```
R = (SPVXSP_target - SPVXSP_prev) / SPVXSP_prev

SVXY_이론가 = SVXY_NAV_prev × (1 - 0.5 × R)
SVIX_이론가 = SVIX_NAV_prev × (1 - R)
```

**다중일 급등 가정 (ETF 가격 상한 — 현실적 시나리오):**

여러 날에 걸쳐 급등하면 매일 리밸런싱으로 포지션을 축소하므로 누적 손실이 줄어들어 ETF 가격이 더 높다.

N일에 걸쳐 VIX 선물 지수가 동일 비율로 상승한다고 가정하면:

```
일간 수익률 r = (SPVXSP_target / SPVXSP_prev)^(1/N) - 1

SVXY_이론가 = SVXY_NAV_prev × (1 - 0.5 × r)^N
SVIX_이론가 = SVIX_NAV_prev × (1 - r)^N
```

**예시: SPVXSP가 현재 5,307에서 10,614 (+100%)까지 상승하는 경우**

| 시나리오 | 일수(N) | 일간 수익률(r) | SVXY 이론가 | SVIX 이론가 |
|---------|---------|--------------|------------|------------|
| 단일일 급등 | 1 | +100.0% | $23.02 | $0.00 |
| 2일 급등 | 2 | +41.4% | $28.95 | $5.50 |
| 3일 급등 | 3 | +26.0% | $30.33 | $6.50 |
| 5일 급등 | 5 | +14.9% | $31.29 | $7.17 |
| 10일 급등 | 10 | +7.2% | $31.95 | $7.62 |

**해석:** 동일한 목표 지수값(+100%)이라도 급등이 여러 날에 분산될수록 ETF 이론가는 더 높다. 이는 일간 리밸런싱 때문이다. 인버스 ETF는 매일 장 마감 시점에 포지션을 조절하는데, 하락(ETF 기준)한 날에는 포지션을 축소하므로 다음 날의 추가 하락 영향이 줄어든다. 따라서 매수자 입장에서는 단일일 급등이 가장 저렴하게 살 수 있는 기회이며, 점진적 급등은 그만큼 매수가가 높아진다. 지정가 매수 주문은 단일일 이론가(하한) 기준으로 설정하되, 체결되지 않을 경우 다중일 이론가(상한)를 참고하여 가격을 올려 재주문한다.

## 4. 매매 전략 설계

### 4.1 전략 개요

VIX 급등(공포 국면)은 통계적으로 평균 회귀(mean reversion) 성격이 강하다. VIX가 급등하면 SVXY/SVIX 가격은 급락하지만, VIX가 정상 수준으로 돌아오면 선물 지수의 콘탱고(contango) 구조 덕분에 SVXY/SVIX는 빠르게 회복한다. 이 전략은 VIX 급등 시 미리 계산된 이론가에 지정가 매수 주문을 배치하여 저가 매수하는 것이다.

### 4.2 VIX 급등 시나리오별 이론가 테이블

아래는 기준일(전일 NAV)로부터 VIX 선물 지수가 단일일에 급등하는 시나리오에서의 이론가이다. 실전에서는 전일 NAV를 매일 업데이트하여 테이블을 재계산해야 한다.

**기준 데이터 (예시):**
- SVXY 전일 NAV: $46.05
- SVIX 전일 NAV: $16.04

| VIX 선물 지수 변동 | VIX 수준 (근사) | SVXY 이론가 | SVIX 이론가 | 매수 비중 |
|-------------------|----------------|------------|------------|---------|
| +20% | ~24 | $41.45 | $12.83 | 10% |
| +30% | ~26 | $39.14 | $11.23 | 10% |
| +40% | ~28 | $36.84 | $9.62 | 15% |
| +50% | ~30 | $34.54 | $8.02 | 15% |
| +60% | ~32 | $32.23 | $6.42 | 15% |
| +70% | ~34 | $29.93 | $4.81 | 15% |
| +80% | ~36 | $27.63 | $3.21 | 10% |
| +90% | ~38 | $25.33 | $1.60 | 5% |
| +100% | ~40 | $23.02 | $0.00 | 5% |

**"매수 비중"**은 전체 투입 자금 대비 해당 가격대에 배치할 비율이다. 중간 구간(+40%~+70%)에 더 많은 비중을 두는 것은 이 구간이 역사적으로 가장 빈번한 급등 고점 영역이기 때문이다.

### 4.3 지정가 매수 주문 배치 전략

**원칙 1: 계단식 지정가 매수 (Laddered Limit Orders)**

전체 투입 자금을 한 번에 투입하지 않고, VIX 선물 지수 변동 구간별로 나누어 지정가 매수 주문을 미리 배치한다.

**원칙 2: 일간 이론가 업데이트**

매일 장 마감 후 새 NAV가 발표되면 이론가 테이블을 재계산하고, 미체결 주문의 가격을 업데이트한다.

```
매일 반복:
  1. 전일 NAV 확인 (SVXY: 4:15 ET, SVIX: TWAP 기반)
  2. 현재 SPVXSP/SHORTVOL 지수값 확인
  3. 각 시나리오별 이론가 재계산
  4. 기존 미체결 주문 취소 → 새 이론가로 재주문
```

**원칙 3: 괴리율 할인**

실전에서는 이론가에서 추가 할인(discount)을 적용한다. VIX 급등 시 ETF 시장가는 NAV보다 할인 거래(디스카운트)되는 경향이 있으므로, 이를 기회로 활용한다.

```
매수 지정가 = 이론가 × (1 - 추가 할인율)
```

추가 할인율 권장: 2%~5% (VIX 급등 강도에 따라 조절)

### 4.4 SVXY vs SVIX 선택 기준

| 판단 기준 | SVXY 선호 | SVIX 선호 |
|----------|----------|----------|
| VIX 급등 예상 폭 | 극단적 (>+80%) | 중간 (+20%~+60%) |
| 위험 허용도 | 낮음 | 높음 |
| 기대 수익률 | 중간 | 높음 |
| VIX 추가 급등 리스크 | 높다고 판단 시 | 낮다고 판단 시 |
| 전멸 리스크 | 이론상 불가 (-0.5x) | 이론상 가능 (-1x) |

**권장 전략:** 투입 자금의 60%는 SVXY(안전), 40%는 SVIX(공격)에 배분한다. SVIX 비중을 높이면 수익률은 높아지지만 VIX 추가 급등 시 손실이 기하급수적으로 커진다.

### 4.5 리스크 관리

**리스크 1: VIX가 예상보다 더 오르는 경우**

대응 방안: 총 투입 자금의 일정 비율(예: 30%)을 예비 자금으로 보유한다. VIX가 예상 상단을 돌파하면 예비 자금으로 추가 매수한다.

**리스크 2: SVIX 전멸 리스크**

SVIX는 -1x이므로 VIX 선물 지수가 하루에 +100% 이상 급등하면 이론상 NAV가 0 이하가 된다. 역사적으로 2018년 2월 5일("Volmageddon")에 XIV(SVIX의 전신 격)가 하루에 약 96% 하락한 사례가 있다. SVIX 투입 금액은 전액 손실을 감수할 수 있는 수준으로 제한해야 한다.

**리스크 3: 경로 의존성에 의한 이론가 편차**

VIX가 여러 날에 걸쳐 급등하면 단일일 이론가보다 실제 ETF 가격이 더 낮아진다(SVXY 기준). 이를 보완하기 위해 이론가 계산 시 "다중일 시나리오"를 함께 참조한다.

**리스크 4: 괴리율(Premium/Discount)**

VIX 극단적 급등 시 ETF 시장가는 NAV 대비 대폭 할인 거래될 수 있다. 이는 매수 기회이자 리스크이다. 시장가가 이론 NAV보다 크게 낮다면 시장의 추가 하락 기대가 반영된 것이므로 신중해야 한다.

**최대 손실 한도 설정:**

```
최대 투입 금액 = 총 투자자산의 X% (권장: 5%~15%)
SVXY 최대 투입: 최대 투입 금액의 60%
SVIX 최대 투입: 최대 투입 금액의 40%
```

## 6. 실전 적용 시 고려사항

### 6.1 데이터 소스

이론가 계산에 필요한 실시간/일간 데이터는 다음과 같다.

- SPVXSP Excess Return Index: Yahoo Finance (^SPVXSP) 또는 S&P Global
- SHORTVOL Index: Volatility Shares 공식 사이트
- VIX 선물 가격 (1개월물, 2개월물): CBOE
- SVXY NAV: ProShares 공식 사이트 (장 마감 후)
- SVIX NAV: Volatility Shares 공식 사이트 (장 마감 후)

### 6.2 VIX와 VIX 선물 지수의 관계

VIX(현물)와 VIX 선물 지수(SPVXSP)는 다르다. SPVXSP는 VIX 선물의 가중평균이므로 VIX 현물보다 변동성이 작다. 일반적으로 VIX가 +50% 급등하면 SPVXSP는 +30%~+40% 정도 상승하는 경향이 있다 (정확한 비율은 기간 구조에 따라 다름). 이론가 계산 시에는 반드시 SPVXSP 지수 변동률을 사용해야 하며, VIX 현물 변동률을 직접 대입하면 안 된다.

### 6.3 비용 고려

일간 수익률 계산에서 비용비율(Expense Ratio)은 일간 기준으로 미세하게 차감된다.

```
일간 비용 차감 = 연간 비용비율 / 365

SVXY: 0.95% / 365 = 0.0026%/일
SVIX: 1.35% / 365 = 0.0037%/일
```

단기 매매(수일~수주)에서는 영향이 미미하나, 정밀 계산 시 반영할 수 있다.

### 6.4 역사적 VIX 급등 사례 참고

| 사건 | 날짜 | VIX 고점 | VIX 선물 지수 변동 | 비고 |
|------|------|---------|-------------------|------|
| COVID-19 | 2020.03 | 82.69 | 수일에 걸쳐 +200% 이상 | 역대 최고 |
| Volmageddon | 2018.02 | 37.32 | 단일일 +96% | XIV 사실상 소멸 |
| 2024.08 엔캐리 | 2024.08 | 65.73 | 수일에 걸쳐 +170% | 빠른 회복 |
| 2022 우크라이나 | 2022.03 | 36.45 | 수주에 걸쳐 +80% | 점진적 상승 |

## 7. 요약

이 알고리즘의 핵심은 세 가지이다.

첫째, SVXY와 SVIX의 일간 리밸런싱 구조를 정확히 이해하고, VIX 선물 지수 변동으로부터 이론가를 올바르게 계산한다. SVXY는 -0.5x, SVIX는 -1x이며, 추종 지수는 각각 SPVXSP와 SHORTVOL이다.

둘째, 경로 의존성을 고려한다. 단일일 이론가(상한)와 다중일 이론가(하한)를 함께 참조하여 지정가 매수 구간을 설정한다.

셋째, 계단식 지정가 매수와 예비자금 보유를 통해 VIX의 추가 급등 리스크를 관리한다. 특히 SVIX는 전멸 리스크가 있으므로 투입 금액을 엄격히 제한한다.
