> 작성일: 2026-04-10  
> 기준 코드: `scripts/screener/screener_v3.py`  
> v3.1은 v3.0 대비 ①한국 시장 제외 ②레짐 필터 ③변동성 스케일링 ④형성 기간 확장(ret12m_skip1) ⑤Buy/Hold Spread ⑥시가총액 가중이 추가된 버전.

---

## 1. 알고리즘 개요

**투자 철학:** "강한 추세 + 꾸준한 상승 + 과열 아님 + 급등 아님"을 동시에 만족하는 미국 주도주에 집중 투자. 한국 시장 제외로 유니버스를 고유동성 대형주 위주로 정제하고, 회전율 감소(히스테리시스)로 실제 거래비용을 최소화.

**핵심 개선 방향 (v3.0 → v3.1):**
- 한국 시장 제외 → 유동성 및 데이터 품질 개선
- ret12m_skip1 추가 → 단기 급등 제거 후 장기 추세 검증
- Buy/Hold Spread → 불필요한 포지션 교체 억제, 거래비용 절감 (회전율 ↓41%)
- 변동성 스케일링 → 고변동성 환경에서 포지션 자동 축소
- 시총 가중 → 실제 매수 가능한 대형주 우선 편입

## 3. 스크리닝 필터 (7개, 전체 통과 필요)

### 3.1 추세 강도: ADX ≥ 20

```python
ADX_THRESH = 20
# ADX(14일) 기준; v3 최적: 기존 25 → 20으로 완화
```

- Average Directional Index ≥ 20: 유효한 추세 존재
- 기간: `ATR_PERIOD = 14`일
- ADX < 20: 횡보/무추세 → 제외

### 3.2 이동평균 정배열: 20MA > 50MA > 200MA

```python
# 최소 200일 데이터 필요 (len(df) < 200 → 즉시 제외)
MA20 = sma(close, 20)
MA50 = sma(close, 50)
MA200 = sma(close, 200)
```

- 단기 > 중기 > 장기 이동평균 순서 (정배열)
- 구조적 상승 추세의 핵심 신호

### 3.3 RSI 범위: 50 ≤ RSI ≤ 77

```python
RSI_LO = 50
RSI_HI = 77   # v3 최적: 75 → 77
```

- RSI(14일) 기준
- RSI < 50: 모멘텀 약함 → 제외
- RSI > 77: 과열 → 급등 후 조정 위험 → 제외

### 3.4 거래량 급등 없음: 최근 20일 내 60일 평균의 3배 초과 없음

```python
VOL_SPIKE = 3.0   # 60일 평균 대비 배수
# (r20["Volume"] > VolMA60 * 3.0).any() → 제외
```

- 최근 20영업일 중 단 하루라도 해당하면 제외
- 작전주·이벤트 드리븐 종목 제거

### 3.5 단기 급등 없음: 최근 5일 내 단일 일봉 ±10% 초과 없음

```python
DAILY_MOVE = 0.10   # ±10%
# (r5["Close"].pct_change().abs() > 0.10).any() → 제외
```

- 최근 5영업일 중 하루라도 ±10% 이상 변동 시 제외
- 모멘텀이 아닌 이벤트 드리븐 움직임 제거

### 3.6 HH-HL 스윙 패턴 ≥ 2회 (60일 윈도우)

```python
HH_HL_MIN    = 2      # 최소 패턴 횟수; v3: 3 → 2
HH_HL_WINDOW = 60     # 최근 60영업일
# 스윙 포인트: ±3봉 내 최고/최저 기준
```

- Higher High + Higher Low가 교대로 2회 이상 확인되어야 통과
- 계단식 상승 구조를 수학적으로 검증
- n=3 봉 기준 스윙 포인트 감지 (단순 비교 아님)

### 3.7 52주 고점 근접: 현재가 ≥ 52주 고점의 75%

```python
PRICE_52W = 0.75   # v3: 80% → 75%
# High52w = df["High"].rolling(252).max()
```

- 52주(252영업일) 고점 대비 25% 이상 하락 종목 제외
- 장기 추세에서 크게 밀리지 않은 종목만 선별

### 3.8 추가 필터: ATR 스톱 이하 진입 금지 (v3.1 신규)


- 이미 하락 추세에 진입한 종목을 스크리닝 단계에서 조기 배제
- v3.0 대비 CAGR 4.4~8.0%p 개선의 핵심 요인

## 4. 복합점수 산식 (v3.1)

```
score = minmax(ADX)           × 0.30   (v3.0: 0.40)
      + minmax(ret3m)          × 0.20   (v3.0: 0.30)
      + minmax(ret12m_skip1)  × 0.20   (v3.1 신규)
      + minmax(sec_str_norm)  × 0.20   (유지)
      + minmax(vol_stab)      × 0.10   (유지)
```

각 항목은 minmax 정규화(0~1) 후 가중합산.

```python
WEIGHTS = dict(
    adx      = 0.30,
    ret3m    = 0.20,
    ret12m   = 0.20,   # ret12m_skip1
    sector   = 0.20,
    vol_stab = 0.10,
)
```

### 각 항목 설명

| 항목 | 가중치 | 계산 방법 |
|---|---|---|
| ADX | 30% | 14일 ATR 기반 방향성 지수 |
| ret3m | 20% | 63영업일 수익률 (최근 3개월) |
| ret12m_skip1 | 20% | 252일 수익률 — 최근 21일 제외 (단기 급등 노이즈 제거) |
| sec_str | 20% | 종목 3M 수익률 − 섹터 ETF 3M 수익률 (같은 섹터 내 상대 강도) |
| vol_stab | 10% | 1 / (거래량 CV + ε), 변동계수 낮을수록 안정 |

### ret12m_skip1 계산 상세

```python
# 273일(=252+21) 이상 데이터 있을 때
ret12m_skip1 = close[-22] / close[-273] - 1

# 252~272일 데이터만 있을 때
ret12m_skip1 = close[-22] / close[-252] - 1
```

- 최근 1개월(21영업일)을 건너뛰어 단기 급등·급락 노이즈 제거
- 형성 기간 확장으로 지속적 추세 확인 (과적합 위험 감소)

## 5. v3.1 신규 기능 상세

### 5.1 시장 레짐 필터

```python
REGIME_FILTER_MODE = "info"   # "off" | "info" | "block"

# SPY MA20 vs MA60 기준
# check_market()에서 is_golden = (SPY_MA20 > SPY_MA60)
```

| 모드 | 동작 |
|---|---|
| `off` | 레짐 필터 적용 안 함 |
| `info` | 데드크로스 시 경고 표시, 스크리닝 계속 실행 (배포 기본값) |
| `block` | SPY MA20 < MA60(데드크로스) 시 빈 결과 반환 (백테스트용) |

- 레짐 기준: SPY 20일 이동평균 vs 60일 이동평균
- `is_golden = True`: 20MA > 60MA (상승 국면)

### 5.2 변동성 스케일링

```python
VOL_TARGET = 0.15   # 목표 연환산 변동성 15%

# SPY 20일 실현변동성(연환산)
spy_vol = ret.tail(20).std() * sqrt(252)
vol_scale = min(VOL_TARGET / spy_vol, 1.0)
```

- SPY 변동성이 15% 이상이면 포지션 비율 자동 축소
- 예: SPY 변동성 30% → 포지션 50%만 투입
- 고변동성 시장에서 손실 제한

### 5.3 Buy/Hold Spread (히스테리시스)

```python
HOLD_SPREAD = 2.5   # 보유 종목 유지 범위 배수

# 매수 대상: TOP_N = 10
# 보유 종목 유지 범위: TOP_N × HOLD_SPREAD = 25위까지
```

- 이미 보유 중인 종목은 순위 25위 이내면 유지 (신규 진입 기준보다 완화)
- 단순 10위 탈락으로 인한 불필요한 매도 억제
- 실측 효과: 총 거래 수 2,888 → 1,703 (↓41%)

### 5.4 시가총액 가중 (sqrt 스케일링)

```python
USE_MKTCAP_WEIGHT = True

# 시총 가중 적용 후 재정렬
score = score_raw × sqrt(market_cap)
```

- 점수가 비슷한 종목 중 시총이 큰 종목 우선 선별
- sqrt 스케일링: 선형 가중보다 소형주 패널티 완화

## 6. ATR 기반 동적 스톱로스

```python
ATR_PERIOD = 14       # ATR 계산 기간
ATR_MULT   = 2.5      # 기본값 (보수적 전략)
# ATR_MULT 전략별: 공격적=1.5, 균형형=2.0, 보수적=2.5

# 스톱가 계산
stop_price = max(High[-20:]) - ATR(14) × ATR_MULT
```

| 전략 | ATR 승수 | 성격 |
|---|---|---|
| 공격적 | 1.5 | 좁은 스톱, 빠른 손절 |
| 균형형 | 2.0 | 중간 |
| 보수적 | 2.5 | 넓은 스톱, 노이즈 무시 |
| 적응형 | 동적 | 국면별 자동 전환 (3계층 복합 판별) |

## 7. 포지션 구성

```python
TOP_N      = 10       # 상위 N개 선정
MAX_WEIGHT = 0.10     # 단일 종목 최대 10%
SIZING_MODE = "score_capped"   # 점수 비례 + 상한 cap
```

### 포지션 사이징 절차 (score_capped)

1. 시총 가중 점수 기준 상위 10개 선정
2. 점수 비례 기본 배분: `w_i = score_i / sum(scores)`
3. 10% 상한 초과 시 초과분을 하위 종목에 재배분 (최대 20회 반복)
4. 변동성 스케일 팩터(`vol_scale`) 적용: 전체 포지션 조정
5. 최종 합계 = `vol_scale × 100%` (시장 변동성 낮을 때 100%, 높을 때 감소)
