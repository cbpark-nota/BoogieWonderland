## 1. 프로젝트 개요

**목적:** 계단식 상승 중인 모멘텀 주식을 자동 스크리닝하고 복합점수로 상위 10개 종목을 선정하는 크로스플랫폼(Flutter) 투자 보조 앱 개발

**대상 시장:** 미국 (NYSE + NASDAQ, S&P500 유니버스) + 국내 (KOSPI 주요 종목)

**투자 철학:** 매크로 모멘텀 추종 — 급등주를 피하고 계단식으로 꾸준히 상승하는 주도주에 투자

## 3. 종목 선정 알고리즘 (v3 최종)

### 스크리닝 조건 (모두 통과해야 후보 등록)
| 조건 | 기준값 | 비고 |
|---|---|---|
| ADX | ≥ 25 | 추세 강도 |
| 이동평균 정배열 | 20MA > 50MA > 200MA | 구조적 상승 |
| RSI | 50 ~ **75** | v2에서 70→75로 완화 |
| 거래량 급등 | 최근 20일 내 60일 평균 3배 초과 없음 | 급등주 제거 |
| 단기 급등 | 최근 5일 내 단일 일봉 ±10% 초과 없음 | |
| HH-HL 패턴 | **스윙 포인트** 기준 3회 이상 | v2에서 일봉→스윙 교체 |
| 52주 신고가 | 현재가 ≥ 52주 고점의 80% | v2에서 추가 |

### 복합점수 산식 (합산 = 1.0)
```
복합점수 = ADX × 0.4
         + 3개월 수익률 × 0.3
         + 섹터 ETF 초과수익률 × 0.2   ← v2에서 ETF 기준으로 교체
         + 거래량 안정성 × 0.1
```

### 섹터 ETF 매핑
```python
SECTOR_ETF = {
    "Technology": "XLK",  "Health Care": "XLV",
    "Financials": "XLF",  "Consumer Disc": "XLY",
    "Industrials": "XLI", "Energy": "XLE",
    "Materials": "XLB",   "Communication": "XLC",
}
```

### 포지션 사이징 (v3)
- 방식: `score_capped` — 복합점수 비례 배분, 단일 종목 최대 **20%** 상한
- 동일비중 대비 샤프지수 개선 예상

### 스톱로스 (v3)
- 방식: **ATR(14) × 2.5** 동적 스톱 (고정 -10% 대신)
- 계산: `스톱가 = 최근 20일 고점 - ATR × 2.5`
- 변동성 높은 종목 → 스톱 넓게, 낮은 종목 → 좁게 자동 조정

### 시장 필터
- SPY 50MA > 200MA (골든크로스) 시 스크리닝 신뢰도 높음
- 데드크로스 시 관망 권장 메시지 출력 (스크리닝은 계속 실행)

### 리밸런싱
- 주기: **매월 말 (월 1회)**
- 보유 종목: 상위 **10개**

## 5. 실행 방법

### 환경 설정
```bash
pip install yfinance pandas-ta pandas numpy matplotlib
```

### 일상 운영 (매일 장 마감 후)
```bash
# 오늘 기준 모멘텀 종목 스크리닝
python screener_v3.py

# 보유 종목 스톱로스 체크
python monitor.py
```

### 보유 종목 관리
```bash
python monitor.py --add NVDA 130.50        # 미국 종목 추가 (매수가 입력)
python monitor.py --add 005930.KS 68000    # 국내 종목 추가
python monitor.py --list                   # 보유 목록 확인
python monitor.py --remove NVDA            # 종목 제거
```

### 백테스트 실행 (최초 1회, 약 30~40분 소요)
```bash
# 단계별 개선 효과 검증
python backtest_steps.py    # 베이스라인 → Step5 비교
python backtest_v3.py       # v3 개선 (ATR + 점수비례) 검증
```

## 7. 미결 사항 (우선순위 순)

1. **백테스트 실행 및 결과 분석**
   - `backtest_steps.py` 실행 → 각 단계 개선 효과 수치 확인
   - `backtest_v3.py` 실행 → ATR 스톱 vs 고정 스톱, 동일비중 vs 점수비례 비교
   - 결과에 따라 파라미터 튜닝 (스윙 n값, ATR 배수, RSI 상한 등)

2. **스윙 포인트 n값 최적화**
   - 현재 n=3 고정
   - n=2,3,4,5 비교 백테스트로 최적값 결정

3. **수익 모델 정의** — 구독형 vs 광고형 vs 프리미엄

4. **법적 고지 의무 검토** — 투자 정보 제공 vs 투자 권유 구분

5. **Flutter 앱 개발 착수**
