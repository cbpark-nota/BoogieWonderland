# 5W/120W 골든크로스 전략 백테스트 결과

## 전략 개요

### 매수 조건
- **신호**: 5주(25일) 이평선이 120주(600일) 이평선을 상향 돌파 (골든크로스)
- **포지션 관리**: 격주 금요일 리밸런싱 시 현재 MA25 > MA600 유지 중인 종목들을 스코어 순 Top 25로 유지
- **스코어 기준**: MA gap ratio = (MA25 − MA600) / MA600
  - 5주 이평이 120주 이평 위에 얼마나 떠 있는지를 측정 → 골든크로스 이후 추세 강도

### 매도 조건 (v3.3 동일)
1. **트레일링 ATR 스톱** (매일 체크, 즉시 청산)
   - `peak = max(누적 peak, 오늘 High)`
   - `stop = max(기존 stop, peak − ATR(14) × 2.5)` ← 스톱가는 상향만
   - Close ≤ stop → 즉시 청산

2. **Top 25 이탈** (격주 금요일 리밸런싱)
   - MA gap ratio 스코어 Top 25 이탈 종목 청산

### 포지션 구조
| 항목 | 값 |
|---|---|
| 포지션 수 | Top 25 동일비중 |
| 리밸런싱 | 격주 금요일 |
| 수수료 | 편도 0.1% |
| ATR 승수 | 2.5 |

## 주의사항 및 한계

### 1. 서바이벌 바이어스 (Survivorship Bias)
- 유니버스로 **현재** S&P 500 / NASDAQ 100 / KOSPI 200 / KOSDAQ 150 구성 종목을 사용
- 2015년 당시 이 종목들의 일부는 해당 지수에 속하지 않았거나 상장 전이었을 수 있음
- 현재 생존·성장한 종목들로 과거를 돌아보므로 실제 성과보다 과대 추정 경향

### 2. MA600 Warm-up
- MA600 계산에 600 거래일(약 2.4년) 필요 → 실질 첫 신호는 2017년 중반부터
- 2015~2017 구간은 사실상 무투자(현금) 기간

### 3. 전략 특성
- 거래 승률 44.7%(절반 이하)지만 수익성 유지 → 손절은 빠르고 수익은 길게 (추세추종)
- MA600을 이미 돌파한 종목만 매수 → 이미 강한 추세 종목에 후행 진입
- 추세 전환기(2022년 금리 인상 등)에서도 ATR 스톱이 낙폭 제한

### 4. 포지션 집중
- Top 25 동일비중이지만, 강세장에서는 Tech 섹터 종목이 상위를 독점할 가능성
